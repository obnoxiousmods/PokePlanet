# Code of Conduct

PokePlanet is a small, friendly project. The rules are short.

**Be decent.** Treat people with respect — in issues, pull requests, commits, and in the game.
Disagree about code, not about people. No harassment, no slurs, no personal attacks, no
sharing others' private information.

**In the game, don't be the reason someone stops playing.** Cheating is a technical problem the
server exists to prevent; harassing other players is a people problem, and it is not welcome.

**Enforcement.** The maintainer may remove comments, commits, or contributions that break this,
and may ban accounts — from the repository or the game — for repeated or serious violations.
Report problems privately to the maintainer.

This is adapted from the spirit of the [Contributor Covenant](https://www.contributor-covenant.org),
kept short on purpose.
